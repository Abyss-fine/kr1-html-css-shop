# GameVault — интернет-магазин компьютерных игр

## Описание проекта

**GameVault** — учебный frontend-проект многостраничного интернет-магазина компьютерных игр, разработанный в рамках дисциплины «Фронтенд и бэкенд разработка».

Проект представляет собой каталог игр студии **Remedy Entertainment**. Пользователи могут просматривать игры, фильтровать их по жанрам, изучать описание и системные требования, переходить к оформлению заказа и отправлять демонстрационные обращения через форму обратной связи.

Дизайн сайта выполнен в тёмной цветовой гамме с красными акцентами.

## Функциональные возможности

- Просмотр главной страницы с подборкой игр.
- Каталог компьютерных игр.
- Фильтрация игр по жанрам.
- Отдельная страница для каждой игры.
- Просмотр описания, стоимости и системных требований.
- Переход к оформлению заказа с автоматическим определением выбранной игры.
- Демонстрационная форма заказа с выбором способа оплаты.
- Модальное окно подтверждения оформления заказа.
- Форма обратной связи с проверкой обязательных полей.
- Модальное окно подтверждения отправки сообщения.
- Адаптивное отображение сайта на различных устройствах.

**Примечание:** проект является учебным. Реальные платежи и отправка сообщений на сервер не выполняются.

## Особенности реализации

### Каталог

Фильтрация игр по жанрам реализована средствами HTML и CSS с использованием радиокнопок и псевдокласса `:has()`.

### Оформление заказа

При нажатии кнопки «Купить игру» пользователь переходит на страницу `order.html`.

Идентификатор выбранной игры передаётся через URL-параметр `game`.

Пример:

```text
order.html?game=control
```

JavaScript определяет выбранную игру и отображает её название, изображение и стоимость.

После заполнения формы пользователь получает демонстрационное подтверждение заказа.

### Обратная связь

На странице контактов реализована форма с полями для имени, электронной почты, темы обращения и сообщения.

После проверки введённых данных отображается модальное окно с подтверждением. Отправка на сервер не производится.
